# Intelligent Relations API — Integration Guide

Partner-facing documentation for the Intelligent Relations API v1.

**Published:** https://intelligentrelations.github.io/api-docs/

## Contents

`index.html` is a single self-contained page — no build step, no dependencies, no
external requests. Open it locally or serve the directory.

## Notes

- The site is served with `noindex` directives (`robots.txt` and a meta tag), so it is
  publicly reachable but excluded from search engines.
- All examples use fictional companies, journalists, outlets and credentials. The base
  URL is a `{host}` placeholder — no real hostnames or keys appear anywhere.

## Updating

Edit `index.html` and push to `main`. GitHub Pages redeploys automatically.
